# ScarsSillyStuff
A general purpose content mod with all sorts of things added.

# Additions:
- 13 Jokers 
- 2 Decks
- 4 Vouchers
- 3 Seals
- 1 Tag
- 1 Sticker
- 3 Blinds
- 2 Challenges
- 1 Spectral Card

# Cross mod stuff list:
- Cryptid: 2 Code cards, 1 Joker
- Familiar: 2 Vouchers
- Paya's Terrible Additions: 1 Joker
